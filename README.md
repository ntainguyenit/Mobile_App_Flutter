## Giới thiệu

**Mobile App Flutter** là ứng dụng tổng hợp các bài tập **Flutter** được xây dựng trong quá trình học môn **Lập trình Mobile**.

# Mobile App Flutter

## Introduction

**Mobile App Flutter** is a collection of **Flutter exercises** developed during the **Mobile Programming** course.

The application uses **Flutter** to build the UI and manage navigation between screens through **Drawer Menu & Navigation**.

Each exercise is designed as an independent **Screen**, allowing users to quickly access features through the **Menu**.

---

## Technologies Used

* **Flutter**
* **Dart**
* **Material Design**
* **Navigator & Routes**
* **Drawer Menu**
* **REST API (News API)**

---

## Exercise List

| **No.** | **Name**                | **Description**                 |
| ------- | ----------------------- | ------------------------------- |
| 1       | Home Page               | Home page interface             |
| 2       | My Place                | Place interface                 |
| 3       | My Classroom            | Classroom interface             |
| 4       | My Phone                | Phone interface                 |
| 5       | My Product              | Product interface               |
| 6       | Change Background Color | Random background color changer |
| 7       | Counter App             | Counter application             |
| 8       | Login Form              | Login form                      |
| 9       | Sign Up Form            | Registration form               |
| 10      | BMI Calculator          | Calculate BMI index             |
| 11      | Feedback Form           | User feedback form              |
| 12      | News                    | Fetch news data from REST API   |

---

## Application Navigation

* The application uses a **Drawer Menu** to display the exercise list
* Each screen includes:

  * A **Menu** for quick navigation
  * A **Back to Home** button
* Navigation between screens is handled using **Navigator & Routes**
